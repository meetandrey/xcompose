# Ergonimic keyboard mappings

Easily enter any kind of special text, from diacritics to Emoji.

## Usage

Download this repository, or any individual file, place it somewhere in your system, then include it in your `~/.XCompose` configuration:
```
include "%L"
include "%H/dist/xcompose/Typography"
```

## Extensions

### Typography Layout

Created by Ilya Birman for macOS and Windows, now ported to Linux. Please refer to author's project page for more information.

To activate the layout, hit the right `Alt` key twice, followed by some other key — you can find a full list on Ilya's website.

For example, a sequence of `Alt, Alt, w` will give you a *✓* sign. See the complete cheat sheet:

[Typography Layout](https://ilyabirman.ru/typography-layout/)
